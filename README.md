# react_base_template
Шаблон преднастроенного проекта React приложения для быстрого старта разработки

## Сборщик проекта
Webpack 5

## Технологии
- Typescript 6
- транспиляция Babel 7
- Suspense-Lazy code splitting

## Стили
- SCSS
- CSS modules
- поддержка цветовых тем

## Стилистика кода
- разработка eslint для проверки typescript кода
- разработка stylelint для проверки стилей

## Архитектура проекта
соответствует архитектуре - [feature-sliced design](https://feature-sliced.design/docs)

## Поддержка локализации. Работа с переводами
отсутствует

## Поддержка адаптивного дизайна страниц.
поддерживается режим мобильного разрешения или десктоп

## Методики тестирования
отсутствует
